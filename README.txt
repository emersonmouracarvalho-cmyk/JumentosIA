JUMENTOSIA — SITE PÚBLICO PARA LANÇAMENTO
==========================================

Este pacote é o site institucional público da JumentosIA, separado do painel interno de operações.
Ainda NÃO está publicado na internet.

PUBLICAR GRATUITAMENTE COM GITHUB PAGES
1. Entre em https://github.com/ e crie uma conta, se necessário.
2. Crie um repositório público chamado jumentosia-site.
3. Faça upload do index.html deste pacote para a raiz do repositório.
4. Abra Settings > Pages.
5. Em Build and deployment, escolha Deploy from a branch; selecione main e /(root); clique Save.
6. Aguarde a publicação e use o endereço que o GitHub mostrar em Pages.
Documentação oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

INDEXAR NO GOOGLE
1. Abra https://search.google.com/search-console/
2. Adicione a propriedade URL prefix com o endereço HTTPS publicado.
3. Complete a verificação que o Search Console indicar.
4. Use Inspeção de URL para testar a página inicial e clique Request indexing.
5. A indexação não é instantânea nem garantida; o Google decide quando e como exibir a página.
Ajuda oficial: https://support.google.com/webmasters/answer/9012289

ANTES DE DIVULGAR
- Configure um e-mail comercial e/ou WhatsApp real no site. O formulário atual não envia os dados: ele prepara uma mensagem para copiar.
- Substitua os conceitos de portfólio demonstrativo por trabalhos reais quando disponíveis. Eles estão identificados como demonstrativos para não sugerir clientes inexistentes.
- Informe a área de atendimento, escopo real dos serviços e política de privacidade conforme necessário.
- Este site institucional não contém o painel interno de leads. Não publique o painel operacional sem autenticação e backend seguros.
- O domínio personalizado é opcional e normalmente tem custo anual. Você pode começar com o endereço gratuito do GitHub Pages.
